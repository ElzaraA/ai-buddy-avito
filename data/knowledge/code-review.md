# Код-ревью

<!-- stage: week2 team: backend audience: intern,buddy,lead -->

Код-ревью: каждый merge request в GitLab проверяет минимум один разработчик команды и наставник. В описании MR укажите, что сделано и как проверить. Мержить можно только при зелёном CI и после апрува.

# Деплой

<!-- stage: week3 team: backend audience: intern,buddy,lead -->

Деплой выполняется через пайплайн GitLab CI после апрува MR. Стажёр не деплоит в прод в первые две недели, выкладку сопровождает наставник.
