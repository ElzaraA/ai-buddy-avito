# Код-ревью

<!-- stage: week2 team: backend audience: intern,buddy,lead -->

Код-ревью: каждый merge request (MR) в GitLab проверяет минимум один разработчик команды и наставник — они и смотрят ваш MR. В описании MR укажите, что сделано и как проверить. Мержить можно только при зелёном CI и после апрува.

# Деплой

<!-- stage: week3 team: backend audience: intern,buddy,lead -->

Деплой (как задеплоить, выкатить в прод): выполняется через пайплайн GitLab CI после апрува MR. Сам выкатывать в прод стажёр не может первые две недели — выкладку сопровождает наставник.
