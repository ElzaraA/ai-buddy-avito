# AI-buddy — фронтенд

React 18 + TypeScript, Vite, TanStack Query, Zustand, Zod.

## Экраны
- **Чат** — вопросы к помощнику. Сообщение уходит сразу (202), ответ агента приходит по SSE, пока что показывается «Помощник думает…». Ответы рисуются по типу:
  `answer` (текст + источники), `action` (карточка результата), `draft` (черновик отгула или заявки на доступ с кнопкой «Отправить заявку»), `refusal` (отказ + имя наставника).
  Если основная модель недоступна и ответила резервная, под ответом появляется пометка «упрощённый режим».
  Если диалог упёрся в лимит сообщений сервера (429 `session_full`), вопрос автоматически уходит в новую сессию.
- **Моя адаптация** (стажёр) — этапы, шаги, % выполнения, следующий шаг, отметка шага выполненным. Шаг «Получить доступы» (и любой шаг, который ждёт заявку) вручную не закрывается: он помечен «ждёт согласования» (номер заявки — в подсказке) и закрывается сам, когда руководитель согласует доступ.
- **Мои заявки** (стажёр) — блок «Ждут вашего подтверждения» с черновиками из чата или от внешнего агента (MCP) и кнопками «отправить» / «отменить»; ниже — отправленные заявки со статусом, комментарием руководителя и кнопкой «отменить».
- **Моя команда** (наставник и руководитель) — плитки сводки (стажёров, средний прогресс, заявок ждут решения, вопросов без ответа), заявки на согласование, прогресс стажёров команды и «Чего нет в базе знаний»: вопросы, на которые помощник не нашёл ответа. Руководитель согласует или отклоняет заявку с комментарием; наставник видит то же без кнопок.
- **Тестовый пользователь** — переключатель в шапке (заголовок `X-Demo-User`): два стажёра backend, стажёр другой команды, наставник, руководитель. Нужен для проверки прав.

Списки заявок, прогресс и кабинет команды обновляются сами раз в 5 секунд — решение руководителя видно у стажёра без перезагрузки.

## Запуск

Нужен запущенный бэкенд на `:8080` (из корня репозитория: `go run ./cmd/server`).

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173, /api проксируется на :8080
```

Другой адрес бэкенда: `BACKEND_URL=http://host:port npm run dev`.

Через Docker (из корня): `docker compose up --build` → http://localhost:5173 (nginx отдаёт сборку и проксирует `/api` на бэкенд).

## Тесты и покрытие

```bash
npm test           # vitest, 72 теста

npm run typecheck
npm run build
```

## Структура
```
src/api/                Zod-схемы ответов бэкенда и API-клиент
src/store/              Zustand: пользователь, сессия, сообщения чата
src/features/chat/      чат + хук useChat (SSE, таймаут 65 с)
src/features/progress/  план адаптации и «Мои заявки»
src/features/team/      кабинет наставника и руководителя
src/components/         карточки ответов агента, форматирование
```

Контракт с бэкендом — `specs/contracts/openapi.yaml`; ответы проверяются Zod-схемами, поэтому расхождение контракта видно сразу, а не в виде пустого экрана.
