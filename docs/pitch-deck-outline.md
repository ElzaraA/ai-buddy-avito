# План презентации — AI-buddy («Бадди»), 10 слайдов

Сценарии демо, скрипт и ответы на вопросы — [`specs/jury-scenarios.md`](../specs/jury-scenarios.md). Цифры с пометкой «гипотеза» не измерены. Данные в демо синтетические.

| # | Слайд | Ключевое сообщение (одна фраза на слайде) | Визуал | Критерии |
|---|---|---|---|---|
| 1 | **Титул** | «Бадди — ИИ-наставник, который закрывает рутину стажёра и первым замечает тех, кто застрял» | Логотип/персонаж «Бадди», QR на демо `ai-buddy-avito-demo.netlify.app`, «Hack&Change 2026 · кейс Авито» | презентация |

| 3 | **Решение** | «Отвечает. Действует с подтверждения. Замечает людей. Считает пользу» | Скриншот рабочего стола: «Мой план», «Мои заявки», «Нужна помощь?», «Пульс», чат с подсказками; 4 подписи-стрелки | UX |

| 6 | **Безопасность** | «Ни одного действия без человека, ни одного ответа без источника» | Схема «черновик → “Отправить заявку” → согласование руководителя»; 4 иконки: подтверждение, маскирование ПДн, роли и команды (чужое — 403), отказ на prompt-injection; подпись «инварианты покрыты тестами» | безопасность, обоснованность |

| 8 | **Архитектура** | «Имитации заменяются адаптерами — агент, API и UI не меняются» | Схема из README: React → API (RBAC, rate limit) → Agent (BM25 + LLM) → Tools → HR/IDM; внешний агент → `POST /mcp`; таблица замен (X-Demo-User → SSO, память → PostgreSQL, mock → внутренняя LLM через `LLM_MOCK=false`); бейджи «покрытие бэкенда 97,2%», «100 параллельных диалогов» | техреализация, внедряемость |

## Заметки к оформлению

- Один тезис на слайд, крупный шрифт; все гипотезы подписаны мелко «гипотеза/оценка».
- Скриншоты — только с реального стенда; надписи новых функций («Пульс», «Сэкономлено наставнику», «Достижения») сверить после их выкатки.
- Дисклеймер в подвале слайдов 3–4: «Прототип на синтетических данных. Инструкции тестовые и не являются регламентами Авито».
