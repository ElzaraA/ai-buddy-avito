# Сценарии AI-buddy

Формат: путь стажёра + критерии приёмки. Каждый критерий закрыт тестом (`specs/traceability.md`) и показывается в видео.

## S1. Отгул (сценарий с действием)
**Путь:** «Хочу взять отгул в пятницу» → помощник готовит черновик заявки на ближайшую пятницу, называет руководителя и советует предупредить наставника → стажёр нажимает «Отправить» → заявка ABS-… в статусе «ждёт согласования» → видна в `GET /actions` после перезагрузки.
Если дата не указана — помощник спрашивает её; ответ «2026-11-20» / «в пятницу» / «завтра» продолжает сценарий.
«Как оформить отгул?» → правила (тестовая инструкция) + имена руководителя и наставника.

Приёмка:
- [x] без явного подтверждения заявка не создаётся (только draft);
- [x] результат виден в чате и в `/actions` после перезагрузки;
- [x] при сбое LLM — понятная ошибка, UI не зависает (событие `error` + `message_done failed`);
- [x] помощник предлагает предупредить наставника, но не пишет ему сам.

## S2. Чек-лист и доступы
**Путь:** «Что мне сделать на этой неделе?» → `checklist_get` → шаги + следующий шаг → «Запроси доступ в GitLab» → черновик заявки REQ-… на GitLab → подтверждение.

Приёмка:
- [x] экран прогресса: шаги, статусы, `percent_done`, `next_step`;
- [x] доступ запрашивается только после подтверждения; ресурс берётся из вопроса;
- [x] стажёр не может менять шаги другого стажёра (403);
- [x] шаг «Получить доступы» автоматически переходит в `waiting` после заявки, в `done` после одобрения, в `todo` после отказа.

## S4. Руководитель и наставник
**Путь:** руководитель открывает входящие (`/team/actions?status=pending`) → согласует отгул стажёра с комментарием → в истории заявки видно, кто и когда решил. Наставник смотрит прогресс стажёров команды и список вопросов, на которые помощник не нашёл ответа, — и дописывает базу знаний.

Приёмка:
- [x] согласовать может только руководитель той же команды; автор, наставник и чужая команда — 403;
- [x] решение окончательное (повтор — 409), записано в историю;
- [x] наставник видит только свою команду; стажёру кабинет недоступен (403);
- [x] вопросы без ответа обезличены.

## S3. Вопросы о команде и инструментах
**Путь:** «Какой стек у команды Backend?» / «Где смотреть логи?» → ответ из базы со ссылкой на источник. Нет ответа в базе («Сколько платят?») → «не нашёл, лучше спросить наставника Ивана Петрова».

Приёмка:
- [x] каждый ответ по базе содержит источник;
- [x] документы чужой команды и mentors_only не попадают в ответ;
- [x] на вопрос вне базы помощник не выдумывает (отказ даже если LLM «знает»).

## Вне рамок
Финансовые операции, бенефиты с выплатами, чувствительные ПДн. Все данные и инструкции — синтетические.
